## Description

*(Up to 4,000 characters)*

---

LifeOS turns pasted schedule text into structured Apple Calendar events and Apple Reminders — without copying and typing each item manually.

**How it works**

Paste any schedule text into LifeOS — a shift roster, an appointment list, or a structured event block. LifeOS reads the text and generates a list of events and tasks for you to review. You check each item, make any edits, and tap Add. That's it.

**Review before anything is created**

Nothing is added to Calendar or Reminders automatically. You approve every item individually. Edit the title, time, location, alert, repeat, or notes before adding.

**What LifeOS parses**

- Calendar events with start time, end time, location, address, travel time, alerts, and recurrence
- Reminders with due dates, priority, lists, and alerts
- Emoji and Unicode titles preserved exactly
- Natural language schedules and structured block formats

**Privacy first**

LifeOS stores your schedule text and settings only on your device. No account. No server. No tracking. Calendar and Reminders access is requested only when you choose to add an item — not at launch.

**Works offline**

Parsing and reviewing your schedule works with no network connection.

## App Review Notes

*(Copy into the App Review Information field)*

LifeOS is a local-first schedule parsing utility.

Users paste or import schedule text. LifeOS parses the text into structured events and tasks. Users review each item before anything is created.

Calendar access is requested only when the user taps "Add" on a calendar event. Reminders access is requested only when the user taps "Add" on a task. No item is created without deliberate user action.

The app works fully offline. No network connection is required to parse, review, or edit schedules. No account or registration is required.
